# 已确认决策

## 技术决策

- 前端框架：`React Native` + `Expo`
- 开发语言：`TypeScript`
- 首要平台：Android
- 数据策略：本地优先
- 主要开发工具：IntelliJ IDEA
- APK 更新渠道：Gitee 发行版
- EAS Update：暂不启用，避免依赖国内可达性不稳定的服务

## 产品决策

- 应用聚焦课程表，不扩展广告、会员、社交和资讯模块
- 默认显示周一到周日
- 默认 12 节课，分为上午 5 节、下午 4 节、晚上 3 节
- 七天横向保持完整显示，节次通过纵向滚动查看
- 当前日期高亮
- 点击课程查看详情，点击空白格添加课程
- 连堂课程合并为一个纵向色块，详情页提供编辑、复制和删除
- 课程数据保存在本机，不要求注册或联网
- 不提供没有实际功能的通用设置入口
- 更新入口放在课程表底部，保持低干扰
- 检查更新时后台读取 Gitee 发行版接口，不自动跳转浏览器
- 初始课表为空，不预置示例课程
- 使用系统安全区域适配 Android 手势及三键导航栏
- 节次数量和每节课的起止时间由用户配置并保存在本机
- 辅助功能统一收纳到右上角更多菜单，保持课表主界面简洁
- 发现新版本时先弹窗显示发行版更新摘要，不自动跳转网页
- 启动画面和应用图标统一使用用户提供的白底手写 “Hello” 图片
- 原始启动图保存在 `assets/splash-screen.jpg`，应用图标使用转换后的 `assets/app-icon.png`

## 决策原因

- 这些选择适合个人课程表的高频查看场景
- 保持技术栈主流，方便以后继续扩展和增加 iOS 支持
- Gitee 比 GitHub 更适合作为国内手机的 APK 下载入口
