# 已确认决策

## 技术决策

- 前端框架：`React Native` + `Expo`
- 开发语言：`TypeScript`
- 唯一目标平台：Android
- iOS 不在当前项目范围内，不创建或维护 iOS 工程、配置和发布流程
- 数据策略：本地优先
- 主要开发工具：IntelliJ IDEA
- APK 更新渠道：Gitee 发行版
- EAS Update：用于 JavaScript、样式和普通资源的小型热更新
- Gitee 发行版：用于原生依赖、权限、图标、启动页等必须整包更新的情况，也是 EAS 不可达时的兜底

## 产品决策

- 应用聚焦课程表，不扩展广告、会员、社交和资讯模块
- 默认显示周一到周日
- 默认 12 节课，分为上午 5 节、下午 4 节、晚上 3 节
- 七天横向保持完整显示，节次通过纵向滚动查看
- 当前日期高亮
- 点击课程查看详情，点击空白格添加课程
- 连堂课程合并为一个纵向色块，详情页提供编辑、复制和删除
- 课程数据保存在本机，不要求注册或联网
- 不提供没有实际功能的通用设置入口
- 更新入口放在课程表底部，保持低干扰
- 检查更新时后台读取 Gitee 发行版接口，不自动跳转浏览器
- 初始课表为空，不预置示例课程
- 使用系统安全区域适配 Android 手势及三键导航栏
- 节次数量和每节课的起止时间由用户配置并保存在本机
- 辅助功能统一收纳到右上角更多菜单，保持课表主界面简洁
- 发现新版本时先弹窗显示发行版更新摘要，不自动跳转网页
- 学校课表导入支持教务系统实际导出的 GBK HTML `.xls`，导入前展示摘要并允许覆盖或去重合并
- 导入教室地点时删除末尾的校区括注，只保留楼栋和教室号
- 课表块中的课程名使用普通字重，地点统一显示为 `@地点`
- 没有星期和节次的网络通识课不生成课表块，按教务系统格式显示在课表底部备注中
- 默认课程时间采用学校作息，每节 45 分钟；旧默认时间自动迁移，自定义时间不覆盖
- 课程、节次和通识课备注使用稳定的 AsyncStorage 键，版本升级只做兼容迁移，不在启动时清空数据
- Android APK 必须保持包名和签名一致并采用覆盖安装，EAS 热更新不得更换运行时存储键
- `1.0.2` 允许一次卸载重装完成签名迁移；此后 release APK 固定使用项目专属证书，保证覆盖更新保留本地数据
- 启动画面和应用图标统一使用用户提供的白底手写 “Hello” 图片
- 原始启动图保存在 `assets/splash-screen.jpg`，应用图标使用转换后的 `assets/app-icon.png`
- “检查更新”优先在后台检查并下载 EAS 热更新，下载完成后由用户选择是否立即重启
- EAS 检查失败时自动继续查询 Gitee 发行版，不向用户暴露网页

## 决策原因

- 这些选择适合个人课程表的高频查看场景
- 保留 React Native + Expo 技术栈，以较低成本完成 Android 界面和原生能力开发
- 聚焦手头可开发和验证的 Android 设备，避免为无法测试的 iOS 平台增加维护成本
- Gitee 比 GitHub 更适合作为国内手机的 APK 下载入口
